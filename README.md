# portfolio_page

## Setup
1. Repo is `portfolio_page`, so `base` in `vite.config.ts` is `"/portfolio_page/"`. Site URL: https://grimjoke.github.io/portfolio_page/
2. Push this folder to `main`.
3. Repo Settings → Pages → Source: **GitHub Actions**.

## Local
```
npm install
npm run dev
```
Edit `src/content.ts` for all text.
